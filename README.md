# Currency Converter API

API desenvolvida com Python e FastAPI para conversão de moedas utilizando a API pública Frankfurter.

## Tecnologias

- Python
- FastAPI
- Pydantic
- Aiohttp
- Requests
- Asyncio

## Funcionalidades

- Conversão síncrona de moedas
- Conversão assíncrona utilizando asyncio.gather
- Validação de parâmetros com Pydantic
- Validação de Path e Query Parameters
- Response Models
- Suporte para múltiplas moedas simultaneamente
